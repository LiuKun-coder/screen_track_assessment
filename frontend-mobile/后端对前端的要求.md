# 后端对前端的要求

## 一、项目概述

本文档描述校园电动车违规管理系统（Spring Boot后端）对前端的集成要求。

**项目信息：**
- 后端服务地址：`http://localhost:8080/api`
- 数据库：MySQL
- 后端技术栈：Spring Boot + MyBatis-Plus
- 认证方式：JWT Token
- 文件上传大小限制：50MB

**前端分类：**
- **Vue3 Web端**：完整功能，包含管理员端和用户端
- **UniApp 微信小程序端**：仅用户端功能，无管理员功能

## 二、通用要求（所有前端）

### 2.1 基本配置

#### API基础URL
```javascript
const BASE_URL = 'http://localhost:8080/api'
```

#### CORS配置
后端已配置跨域支持：
- 允许所有来源（开发环境）
- 支持方法：GET, POST, PUT, DELETE, OPTIONS
- 允许携带凭证
- 允许所有请求头

### 2.2 JWT认证机制

#### Token获取
用户登录成功后，后端返回JWT Token：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": 1,
      "username": "admin",
      "name": "管理员",
      "role": "admin",
      ...
    }
  },
  "timestamp": "2024-01-31T15:30:00"
}
```

#### Token使用
所有需要认证的接口（除登录/注册外），必须在请求头中携带Token：

```javascript
// 请求头配置
headers: {
  'Authorization': 'Bearer ' + token,
  'Content-Type': 'application/json'
}
```

#### Token过期处理
- Token有效期：24小时（86400000毫秒）
- 过期后需重新登录
- 返回401状态码时，应跳转登录页

#### 公开接口（无需Token）
- `POST /auth/login` - 登录
- `POST /auth/register` - 注册（如有）
- `POST /upload` - 文件上传（注意：当前无需认证，生产环境建议修改）

### 2.3 统一响应格式

所有接口返回统一的JSON格式：

**成功响应：**
```json
{
  "code": 200,
  "message": "success",
  "data": { /* 业务数据 */ },
  "timestamp": "2024-01-31T15:30:00"
}
```

**错误响应：**
```json
{
  "code": 400/401/500,
  "message": "错误描述",
  "data": null,
  "timestamp": "2024-01-31T15:30:00"
}
```

**常见状态码：**
- `200`：成功
- `400`：请求参数错误
- `401`：未授权（Token无效或未登录）
- `500`：服务器内部错误

### 2.4 分页数据格式

使用MyBatis-Plus的IPage分页格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [/* 数据列表 */],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  }
}
```

**分页参数：**
- `page`: 当前页码（从1开始）
- `pageSize`: 每页数量

### 2.5 日期时间格式

**请求参数：**
- 日期：`yyyy-MM-dd`（如：2024-01-31）
- 日期时间：ISO 8601格式（如：2024-01-31T15:30:00）

**响应数据：**
- 后端返回LocalDateTime格式：`2024-01-31T15:30:00`

### 2.6 文件上传

**接口：** `POST /upload`

**请求方式：** multipart/form-data

**参数：**
- `file`: 文件对象

**返回：**
```json
{
  "code": 200,
  "message": "success",
  "data": "http://localhost:8080/api/uploads/2024/01/31/abc123.jpg"
}
```

**注意事项：**
- 返回完整的文件访问URL
- URL可直接用于<img>标签或其他场景
- 最大上传大小：50MB

### 3.3 前端实现建议

#### 3.3.1 请求拦截器（Axios示例）

```javascript
import axios from 'axios'

const request = axios.create({
  baseURL: 'http://localhost:8080/api',
  timeout: 10000
})

// 请求拦截器
request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers['Authorization'] = 'Bearer ' + token
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器
request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      // 错误处理
      if (res.code === 401) {
        // Token过期，跳转登录
        localStorage.removeItem('token')
        window.location.href = '/login'
      }
      return Promise.reject(new Error(res.message || 'Error'))
    }
    return res.data
  },
  error => {
    return Promise.reject(error)
  }
)

export default request
```

#### 3.3.2 权限路由守卫

```javascript
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const userInfo = JSON.parse(localStorage.getItem('userInfo') || '{}')
  
  // 需要登录的页面
  if (to.meta.requiresAuth && !token) {
    next('/login')
    return
  }
  
  // 需要管理员权限的页面
  if (to.meta.requiresAdmin && userInfo.role !== 'admin') {
    next('/403')
    return
  }
  
  next()
})
```

### 4.3 小程序特殊要求

#### 4.3.1 请求配置（uni.request）

```javascript
// request.js
const BASE_URL = 'http://localhost:8080/api'

function request(options) {
  const token = uni.getStorageSync('token')
  
  return new Promise((resolve, reject) => {
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: {
        'Content-Type': 'application/json',
        'Authorization': token ? 'Bearer ' + token : ''
      },
      success: (res) => {
        if (res.data.code === 200) {
          resolve(res.data.data)
        } else if (res.data.code === 401) {
          // Token过期
          uni.removeStorageSync('token')
          uni.reLaunch({ url: '/pages/login/login' })
          reject(new Error('未授权'))
        } else {
          uni.showToast({
            title: res.data.message || '请求失败',
            icon: 'none'
          })
          reject(new Error(res.data.message))
        }
      },
      fail: (err) => {
        uni.showToast({
          title: '网络错误',
          icon: 'none'
        })
        reject(err)
      }
    })
  })
}

export default request
```

#### 4.3.2 文件上传（uni.uploadFile）

```javascript
function uploadFile(filePath) {
  const token = uni.getStorageSync('token')
  
  return new Promise((resolve, reject) => {
    uni.uploadFile({
      url: BASE_URL + '/upload',
      filePath: filePath,
      name: 'file',
      header: {
        'Authorization': token ? 'Bearer ' + token : ''
      },
      success: (res) => {
        const data = JSON.parse(res.data)
        if (data.code === 200) {
          resolve(data.data) // 返回文件URL
        } else {
          reject(new Error(data.message))
        }
      },
      fail: reject
    })
  })
}
```

## 六、常见问题与注意事项

### 6.1 Token管理
- 登录成功后务必保存Token和用户信息
- 每次请求携带Token
- 401错误时清除本地Token并跳转登录

### 6.2 日期格式
- 请求参数使用`yyyy-MM-dd`格式
- 后端返回ISO 8601格式，前端需要格式化显示

### 6.3 JSON字段解析
- `evidenceImages`、`coordinates`、`trackPoints`、`evidenceFiles`等字段为JSON字符串
- 前端需要使用`JSON.parse()`解析后使用

### 6.4 文件上传
- 先调用`/upload`接口上传文件
- 获得URL后再提交表单数据
- 注意文件大小限制（50MB）

### 6.5 分页参数
- page从1开始计数
- pageSize默认为10

### 6.6 权限控制
- Web端需要区分admin和user角色
- 小程序端只实现user功能，不需要权限判断

### 6.7 错误处理
- 统一在拦截器中处理错误状态码
- 401跳转登录页
- 其他错误显示message提示

> **重要提示**：以下功能需要**后端新增接口**支持。详细的实施计划和接口设计请查看：`implementation_plan.md`

基于补充需求，UniApp小程序端需要以下新增功能：

### 7.1 微信授权登录（必需）

**需求说明：**
- 小程序使用微信一键登录，无需用户名密码
- 用户第一次登录时自动创建账号
- 支持绑定已有账号（可选）

**后端需要新增的接口：**

#### ① 微信小程序登录
```
POST /auth/wechat/login
Content-Type: application/json
无需Authorization（公开接口）

请求体：
{
  "code": "wx_login_code",      // wx.login()获取的code
  "nickName": "用户昵称",        // 可选
  "avatarUrl": "头像URL"        // 可选
}

响应：
{
  "code": 200,
  "data": {
    "token": "jwt_token",
    "userInfo": {
      "id": 1,
      "username": "wx_user_xxx",
      "openid": "oxxx",
      "isNewUser": true,          // 是否新用户
      "role": "user",
      ...
    }
  }
}
```

**后端实施要点：**
1. 创建`WechatAuthController`
2. 调用微信API：`https://api.weixin.qq.com/sns/jscode2session`
3. 获取`openid`和`session_key`
4. 查询或创建用户账号
5. 返回JWT Token

**数据库要求：**
- 新建表：`sys_user_wechat`（微信用户关联表）
- 字段：`user_id`, `openid`, `unionid`, `session_key`, `nickname`, `avatar`

**配置要求：**
```yaml
# application.yml
wechat:
  miniapp:
    app-id: your_wx_appid
    app-secret: your_wx_app_secret
```

**前端示例：**
```javascript
// 微信授权登录
async wechatLogin() {
  // 1. 获取微信登录code
  const loginRes = await uni.login({ provider: 'weixin' })
  
  // 2. 获取用户信息（可选）
  const userProfileRes = await uni.getUserProfile({
    desc: '用于获取用户信息'
  })
  
  // 3. 调用后端接口
  const res = await request({
    url: '/auth/wechat/login',
    method: 'POST',
    data: {
      code: loginRes.code,
      nickName: userProfileRes.userInfo.nickName,
      avatarUrl: userProfileRes.userInfo.avatarUrl
    }
  })
  
  // 4. 保存token
  uni.setStorageSync('token', res.token)
  uni.setStorageSync('userInfo', res.userInfo)
}
```

### 7.2 实时轨迹上传（必需）

**需求说明：**
- 小程序后台获取用户位置
- 定期上传轨迹点到后端
- 支持批量上传减少请求次数

**后端需要新增的接口：**

#### ① 上传轨迹点
```
POST /tracks/upload
Authorization: Bearer {token}
Content-Type: application/json

请求体：
{
  "trackPoints": [
    {
      "latitude": 39.916527,
      "longitude": 116.397128,
      "speed": 15.5,               // km/h
      "timestamp": "2024-01-31T10:30:00"
    },
    ...
  ]
}

响应：
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "receivedCount": 10           // 接收到的轨迹点数量
  }
}
```

**后端实施要点：**
1. 创建`TrackController.uploadTrackPoints()`方法
2. 批量保存轨迹点数据
3. 可以按日期聚合存储（优化查询性能）
4. 考虑数据存储优化（压缩、分表等）

**前端示例：**
```javascript
// 后台定位与轨迹上传
export default {
  data() {
    return {
      locationTimer: null,
      trackPointsCache: []        // 缓存轨迹点
    }
  },
  
  onShow() {
    this.startLocationTracking()
  },
  
  onHide() {
    this.stopLocationTracking()
  },
  
  methods: {
    // 开始定位追踪
    startLocationTracking() {
      // 1. 请求定位权限
      uni.authorize({
        scope: 'scope.userLocation',
        success: () => {
          this.startTracking()
        }
      })
    },
    
    // 启动定时获取位置
    startTracking() {
      // 每30秒获取一次位置
      this.locationTimer = setInterval(() => {
        uni.getLocation({
          type: 'gcj02',
          success: (res) => {
            // 添加到缓存
            this.trackPointsCache.push({
              latitude: res.latitude,
              longitude: res.longitude,
              speed: res.speed || 0,
              timestamp: new Date().toISOString()
            })
            
            // 每10个点上传一次
            if (this.trackPointsCache.length >= 10) {
              this.uploadTrackPoints()
            }
          }
        })
      }, 30000) // 30秒
    },
    
    // 上传轨迹点
    async uploadTrackPoints() {
      if (this.trackPointsCache.length === 0) return
      
      try {
        await request({
          url: '/tracks/upload',
          method: 'POST',
          data: {
            trackPoints: this.trackPointsCache
          }
        })
        // 上传成功后清空缓存
        this.trackPointsCache = []
      } catch (error) {
        console.error('轨迹上传失败', error)
        // 失败不清空缓存，下次重试
      }
    },
    
    // 停止定位
    stopLocationTracking() {
      if (this.locationTimer) {
        clearInterval(this.locationTimer)
        // 上传剩余的轨迹点
        this.uploadTrackPoints()
      }
    }
  }
}
```

**注意事项：**
> [!WARNING]
> 1. 定位频率不要太高，避免耗电和产生大量数据
> 2. 建议使用批量上传，减少网络请求
> 3. 失败时应有重试机制
> 4. 需要申请用户定位权限

### 7.3 消息推送（必需）

**需求说明：**
- 违规记录创建时推送通知给用户
- 申诉处理完成时推送结果

**后端需要新增的接口：**

#### ① 订阅消息推送
```
POST /notification/subscribe
Authorization: Bearer {token}
Content-Type: application/json

请求体：
{
  "type": "wechat_miniapp",
  "templateId": "xxx",           // 订阅消息模板ID
  "formId": "xxx"                // 微信formId（如需要）
}

响应：
{
  "code": 200,
  "message": "订阅成功"
}
```

#### ② 获取消息列表（站内消息）
```
GET /notifications?page=1&pageSize=10&type=violation
Authorization: Bearer {token}

查询参数：
- page: 页码
- pageSize: 每页数量
- type: 消息类型（violation-违规, appeal-申诉, system-系统）

响应：IPage<Notification>
```

#### ③ 标记消息已读
```
PUT /notifications/{id}/read
Authorization: Bearer {token}

响应：Result<Void>
```

**Notification数据结构：**
```typescript
interface Notification {
  id: number;
  userId: number;
  type: string;                // violation, appeal, system
  title: string;               // 标题
  content: string;             // 内容
  relatedId: number;           // 关联业务ID
  status: string;              // unread, read
  createTime: string;
}
```

**后端实施要点：**
1. 创建`NotificationController`和`NotificationService`
2. 创建`biz_notification`表
3. 在违规创建、申诉处理等业务中触发推送
4. 集成微信订阅消息API（可选）

**数据库要求：**
```sql
CREATE TABLE biz_notification (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  type VARCHAR(32) NOT NULL,
  title VARCHAR(128) NOT NULL,
  content TEXT,
  related_id BIGINT,
  status VARCHAR(16) DEFAULT 'unread',
  create_time DATETIME NOT NULL,
  INDEX idx_user_id (user_id),
  INDEX idx_status (status)
);
```

**前端示例：**
```javascript
// 订阅消息
async subscribeMessage() {
  const res = await uni.requestSubscribeMessage({
    tmplIds: ['your_template_id']
  })
  
  if (res['your_template_id'] === 'accept') {
    // 订阅成功，保存到后端
    await request({
      url: '/notification/subscribe',
      method: 'POST',
      data: {
        type: 'wechat_miniapp',
        templateId: 'your_template_id'
      }
    })
  }
}

// 获取消息列表
async getNotifications() {
  const res = await request({
    url: '/notifications',
    method: 'GET',
    data: {
      page: 1,
      pageSize: 20,
      type: 'all'
    }
  })
  this.notifications = res.records
}
```

**微信小程序配置：**
1. 在微信公众平台配置订阅消息模板
2. 获取模板ID
3. 在合适的时机引导用户订阅（如提交申诉后）

### 7.4 违规记录筛选搜索（必需）

**需求说明：**
- 支持按违规类型筛选
- 支持按状态筛选
- 支持时间范围查询

**后端需要调整的接口：**

#### ① 增强现有接口参数
```
GET /violations/my?page=1&pageSize=10&type=超速&status=pending&startTime=2024-01-01&endTime=2024-01-31
Authorization: Bearer {token}

新增查询参数：
- type: 违规类型（超速、违停、逆行、闯红灯）
- status: 状态（pending、processed）
- startTime: 开始时间（yyyy-MM-dd）
- endTime: 结束时间（yyyy-MM-dd）

响应：IPage<ViolationVO>
```

**后端实施要点：**
1. 修改`ViolationController.getMyViolations()`方法
2. 添加查询条件支持
3. 使用MyBatis-Plus的`QueryWrapper`动态构建查询

**前端示例：**
```vue
<template>
  <view class="filter-container">
    <!-- 违规类型筛选 -->
    <picker :range="violationTypes" @change="onTypeChange">
      <view class="picker">
        类型：{{ selectedType || '全部' }}
      </view>
    </picker>
    
    <!-- 状态筛选 -->
    <picker :range="statusOptions" @change="onStatusChange">
      <view class="picker">
        状态：{{ selectedStatus || '全部' }}
      </view>
    </picker>
    
    <!-- 时间范围 -->
    <picker mode="date" @change="onStartTimeChange">
      <view class="picker">
        开始时间：{{ startTime || '选择' }}
      </view>
    </picker>
    
    <picker mode="date" @change="onEndTimeChange">
      <view class="picker">
        结束时间：{{ endTime || '选择' }}
      </view>
    </picker>
    
    <!-- 搜索按钮 -->
    <button @click="searchViolations">搜索</button>
  </view>
  
  <!-- 违规列表 -->
  <view class="violation-list">
    <view v-for="item in violations" :key="item.id" class="violation-item">
      <!-- 违规信息展示 -->
    </view>
  </view>
</template>

<script>
export default {
  data() {
    return {
      violationTypes: ['全部', '超速', '违停', '逆行', '闯红灯'],
      statusOptions: ['全部', '待处理', '已处理'],
      selectedType: '',
      selectedStatus: '',
      startTime: '',
      endTime: '',
      violations: [],
      page: 1,
      pageSize: 10
    }
  },
  
  methods: {
    async searchViolations() {
      const params = {
        page: this.page,
        pageSize: this.pageSize
      }
      
      // 添加筛选条件
      if (this.selectedType && this.selectedType !== '全部') {
        params.type = this.selectedType
      }
      
      if (this.selectedStatus) {
        params.status = this.selectedStatus === '待处理' ? 'pending' : 'processed'
      }
      
      if (this.startTime) {
        params.startTime = this.startTime
      }
      
      if (this.endTime) {
        params.endTime = this.endTime
      }
      
      try {
        const res = await request({
          url: '/violations/my',
          method: 'GET',
          data: params
        })
        this.violations = res.records
      } catch (error) {
        uni.showToast({
          title: '查询失败',
          icon: 'none'
        })
      }
    }
  }
}
</script>
```

### 7.5 地图轨迹显示（已支持）

**需求说明：**
- 显示用户某段时间内的运动轨迹
- 不需要显示电子围栏

**无需新增接口**，使用现有接口即可：
- `GET /tracks/byDate` - 获取某日期的轨迹
- `GET /tracks/list` - 获取轨迹列表

**前端实现建议：**
```vue
<template>
  <view class="track-container">
    <!-- 日期选择 -->
    <picker mode="date" @change="onDateChange">
      <view class="picker">
        选择日期：{{ selectedDate }}
      </view>
    </picker>
    
    <!-- 地图组件 -->
    <map
      :latitude="center.latitude"
      :longitude="center.longitude"
      :scale="15"
      :polyline="polyline"
      :markers="markers"
      class="map"
    />
    
    <!-- 轨迹信息 -->
    <view class="track-info">
      <text>总里程：{{ distance }} km</text>
      <text>用时：{{ duration }}</text>
    </view>
  </view>
</template>

<script>
export default {
  data() {
    return {
      selectedDate: this.formatDate(new Date()),
      center: { latitude: 39.9, longitude: 116.4 },
      polyline: [],
      markers: [],
      distance: 0,
      duration: ''
    }
  },
  
  onLoad() {
    this.loadTrackData()
  },
  
  methods: {
    async loadTrackData() {
      try {
        const tracks = await request({
          url: '/tracks/byDate',
          method: 'GET',
          data: {
            date: this.selectedDate
          }
        })
        
        if (tracks && tracks.length > 0) {
          const track = tracks[0]
          this.renderTrack(track)
        }
      } catch (error) {
        uni.showToast({
          title: '加载失败',
          icon: 'none'
        })
      }
    },
    
    renderTrack(track) {
      // 解析轨迹点
      const trackPoints = JSON.parse(track.trackPoints)
      
      if (trackPoints.length === 0) return
      
      // 设置地图中心
      this.center = {
        latitude: trackPoints[0].lat,
        longitude: trackPoints[0].lng
      }
      
      // 设置轨迹线
      this.polyline = [{
        points: trackPoints.map(p => ({
          latitude: p.lat,
          longitude: p.lng
        })),
        color: '#0091FF',
        width: 4,
        arrowLine: true
      }]
      
      // 设置起点和终点标记
      this.markers = [
        {
          id: 1,
          latitude: trackPoints[0].lat,
          longitude: trackPoints[0].lng,
          iconPath: '/static/start.png',
          width: 30,
          height: 30,
          label: { content: '起点' }
        },
        {
          id: 2,
          latitude: trackPoints[trackPoints.length - 1].lat,
          longitude: trackPoints[trackPoints.length - 1].lng,
          iconPath: '/static/end.png',
          width: 30,
          height: 30,
          label: { content: '终点' }
        }
      ]
      
      // 设置轨迹信息
      this.distance = track.distance
      this.duration = this.calculateDuration(track.startTime, track.endTime)
    },
    
    formatDate(date) {
      const year = date.getFullYear()
      const month = String(date.getMonth() + 1).padStart(2, '0')
      const day = String(date.getDate()).padStart(2, '0')
      return `${year}-${month}-${day}`
    },
    
    calculateDuration(start, end) {
      // 计算时长
      const startTime = new Date(start)
      const endTime = new Date(end)
      const diff = endTime - startTime
      const hours = Math.floor(diff / 3600000)
      const minutes = Math.floor((diff % 3600000) / 60000)
      return `${hours}小时${minutes}分钟`
    },
    
    onDateChange(e) {
      this.selectedDate = e.detail.value
      this.loadTrackData()
    }
  }
}
</script>

<style>
.map {
  width: 100%;
  height: 500px;
}
</style>
```
