🎨 设计理念说明

🌿

温暖自然的色调

采用米色、暖灰、鼠尾草绿等自然色系，远离冷峻的科技蓝，营造亲切感。

✨

简洁克制的装饰

去除霓虹发光、复杂边框、网格背景等过度装饰，让内容本身成为焦点。

📝

友好的文案语气

"让校园出行更安全"而非"智能监控平台"，用人话说话，像朋友一样。

👋

有温度的交互

柔和的动画过渡、舒适的留白、克制的圆角，一切都恰到好处。

这是一个静态UI设计预览 · 用于审阅新的设计风格方向
