# 校园电动车监管系统｜车载终端硬件方案（STM32，36V 输入，单件≈100 元，体积压缩）

本文把方案细化到“可以直接画原理图”的程度：给出两套可落地方案（推荐集成度更高的一套），并提供关键器件+阻容感取值与连接关系（RefDes 级别）。所有射频/电源部分请在打样前对照所选芯片与模组的最新硬件设计指南再做一次校核。

---

## 0. 结论：在 36V、100 元、体积压缩条件下怎么选

- **强烈推荐（方案 A2）**：STM32 + **蜂窝（Cat‑M/NB）+ GNSS 二合一模组**（例如 SIM7080G 或 Quectel BG95 系列带 GNSS 版本）
  - 优点：少一颗 GNSS 模组、少一套天线/供电/接口，PCB 更小、BOM 更低
  - 适配业务：定位、轨迹、围栏、超速完全够用；上报走 MQTT/HTTP 小数据很合适
- **备选（方案 A1）**：STM32 + **4G Cat.1 模组** + 独立 GNSS（定位体验可能更好，但更贵更占板）

下面给出两套的“可画图”级电路块。若你不确定网络覆盖，先做 A2（Cat‑M/NB+GNSS）工程样机最省钱。

## 1. 方案 A2（推荐）：SIM7080G（Cat‑M/NB + GNSS）+ STM32 + SPI Flash

### 1.1 系统框图

- 36V 电池（实际满电可能到 42V）→ 输入保护 → HV Buck 输出 **4.0V**（给蜂窝模组）
- 4.0V → LDO 输出 **3.3V**（给 STM32、Flash、IMU）
- STM32 UART ↔ SIM7080G（AT 指令、上报、GNSS 数据/或 NMEA）
- STM32 SPI ↔ W25Q64（离线轨迹缓存）
- SIM 卡座 ↔ SIM7080G
- LTE 天线、GNSS 天线 ↔ SIM7080G（两路 u.FL）

## 2. “可直接画原理图”的连接与器件（方案 A2）

### 2.1 供电与保护（36V → 4.0V → 3.3V）

#### 2.1.1 输入端（J1 → 保护 → 滤波）

- J1：电源输入连接器（2Pin）
  - 推荐：XT30U‑M（板端）或防水航插（量产看结构）
- F1：保险丝（贴片保险丝或自恢复）
  - 方案：贴片保险丝 2A/63V（如 Littelfuse 0467 系列同等）
  - 若要更省：自恢复保险丝 1.85A/60V（如 Bourns MF‑R185）
- D1：反接保护二极管（成本优先的串联肖特基）
  - SS56（5A/60V，SMB）
- D2：TVS 管（浪涌/尖峰钳位）
  - SMBJ58A（58V，SMB）用于 36V 系统（考虑满电 42V + 余量）
- C1：输入电解/固态（吸收浪涌）
  - 100µF / 63V（固态/低 ESR 更好）
- C2、C3：输入陶瓷（靠近 Buck VIN）
  - 2 × 4.7µF / 100V / X7R（1206）
- FB1：磁珠（抑制高频噪声回灌）
  - 600Ω@100MHz，≥2A（1206）

连接关系（可照抄网络名）：

- J1+ → F1 → D1 → VIN_RAW
- VIN_RAW 对 GND 并联 D2、C1
- VIN_RAW → FB1 → VIN_BUCK
- VIN_BUCK 对 GND 并联 C2、C3

#### 2.1.2 高压降压 Buck（36~42V → 4.0V / 2.5A 峰值）

选型目标：输入耐压 ≥60V、小体积、成本可控、能扛蜂窝脉冲电流。

- U1：TI TPS54260DGQR（60V，2.5A，VSON‑10）
- L1：电感 10µH（饱和电流 ≥4A，低 DCR）
  - 示例：Würth 744771110（或国产同等 10µH 4~5A）
- D3：肖特基（如采用非同步 Buck 需要；TPS54260 是非同步，需要外置肖特基）
  - SS34（3A/40V）电压不够；建议 **SS54（5A/40V）也不够**
  - 这里必须选耐压更高：**SS56（5A/60V，SMB）**（与 D1 可同型号，便于采购）
- C4、C5：输出固态/聚合物（靠近 D3/L1 后）
  - 2 × 220µF / 6.3V（聚合物，低 ESR，能扛脉冲）
- C6、C7：输出陶瓷
  - 2 × 22µF / 10V / X5R（0805/1206）
- RFBT、RFBB：反馈电阻（设定 4.0V）
  - TPS54260 Vref=0.8V，Vout=0.8×(1+Rtop/Rbot)
  - 取 RFBB=10k，RFBT=40.2k（E96），Vout≈4.016V
- Cff：前馈电容（跨 RFBT，提高瞬态）
  - 100pF（NP0 优先）
- COMP 网络（起步值，后续按波形微调）
  - Rcomp=10k
  - Ccomp=2.2nF
  - Ccomp2=100pF（并联在 Ccomp 或按 datasheet 推荐连接）

TPS54260 关键引脚连接（按典型应用画）：

- VIN → VIN_BUCK（近端并联 C2/C3 到 GND）
- GND/PowerPAD → 大地铜皮（多过孔）
- SW → L1 → VOUT_4V
- SW 同时接 D3（D3 阴极接 SW，阳极接 GND）
- VOUT_4V 对 GND 并联 C4/C5/C6/C7
- VSENSE → 分压点（RFBT 上端接 VOUT_4V，下端 RFBB 接 GND；VSENSE 接两者中点）
- EN：上拉到 VIN_BUCK（或 MCU 控制；若 MCU 控制，EN 串 10k，EN 对 GND 加 100nF 防抖）
- COMP：按上面补偿网络到 GND
- BOOT：按 datasheet 接自举电容（通常 100nF）到 SW（TPS54260 需要按推荐连接）

#### 2.1.3 3.3V 线性稳压（4.0V → 3.3V）

- U2：AP2112K‑3.3（600mA，SOT‑23‑5）
- C8：U2 输入
  - 10µF / 10V
- C9：U2 输出
  - 10µF / 10V

连接：

- U2 IN ← VOUT_4V
- U2 OUT → VOUT_3V3
- U2 EN → VOUT_4V（常开）或 MCU 控制
- C8：IN‑GND；C9：OUT‑GND

### 2.2 蜂窝+GNSS 模组（SIM7080G）电路块

#### 2.2.1 模组与供电去耦（最关键）

- U3：SIMCom SIM7080G（Cat‑M/NB + GNSS）
- VBAT 去耦（必须贴近模组 VBAT 引脚）：
  - C10：470µF / 6.3V 聚合物（1 颗）
  - C11、C12：2 × 100µF / 6.3V 聚合物（可选，视板空间）
  - C13、C14、C15：3 × 22µF / 10V X5R（0805/1206）
  - C16、C17：2 × 100nF / 16V（0402/0603）

连接：

- VOUT_4V →（可串一个 0Ω 作为电流测量/隔离位）→ VBAT_SIM
- VBAT_SIM → U3 VBAT
- 上述 C10~C17 全部：VBAT_SIM 对 GND 并联

#### 2.2.2 SIM 卡座

- J2：Nano‑SIM 卡座（推拉式）
  - Molex 503398‑1892（或国产同等）
- ESD（靠近卡座）：
  - D4：ESD 保护阵列（SIMCLK/SIMDATA/SIMRST）
    - Nexperia PESD5V0S3UL（示例，选 3 线阵列/或 4 线阵列）

连接（按模组 SIM 接口）：

- SIM_VDD ← U3 SIM_VDD
- SIM_CLK ↔ U3 SIM_CLK（串联 R：R1=22Ω，靠近模组）
- SIM_DATA ↔ U3 SIM_DATA（串联 R：R2=22Ω）
- SIM_RST ↔ U3 SIM_RST（串联 R：R3=22Ω）
- SIM_DET（可选）：卡座检测脚 → MCU GPIO（上拉 100k 到 3V3）

#### 2.2.3 UART、控制脚、状态灯

- MCU ↔ U3：
  - TXD：MCU_USART1_TX → U3 RXD（串 22Ω）
  - RXD：MCU_USART1_RX ← U3 TXD（串 22Ω）
- PWRKEY：
  - MCU GPIO →（NPN 或 NMOS 开漏拉低）→ U3 PWRKEY
  - 推荐：Q1=2N7002（SOT‑23），R4=100k 下拉，R5=10k 栅极串
- RESET（如模组支持硬复位脚）：
  - MCU GPIO → Q2（2N7002）→ U3 RESET
- NETLIGHT：
  - U3 NETLIGHT → LED1（串 R6=1k 到 3V3 或到 GND 按模组推挽类型决定）

---

### 2.3 天线与射频接口（LTE + GNSS）

- J3：LTE 天线座 u.FL
  - Hirose U.FL‑R‑SMT
- J4：GNSS 天线座 u.FL
  - Hirose U.FL‑R‑SMT
- ESD（靠近天线座）：
  - D5、D6：RF ESD（超低电容）
    - Semtech RClamp0502B（示例；也可选 Nexperia PESD5V 系列 RF 低电容器件）

连接：

- U3 LTE_ANT → J3 中心脚；J3 外壳→GND（多过孔围栏）
- U3 GNSS_ANT → J4 中心脚；J4 外壳→GND
- D5/D6：中心脚到 GND（按器件推荐走线）
- 走线：50Ω 微带/带状线；天线区 keepout，远离 Buck 电感与 SW 节点

---

### 2.4 MCU（STM32）最小系统（低成本小封装）

- U4：STM32G031K8T6（LQFP‑32，低成本，UART/SPI 足够）
  - 若你希望更大 Flash/RAM：STM32G071KBU6（QFN‑32/UFQFPN 更小）
- 去耦电容（贴近每个 VDD）：
  - C20、C21、C22：3 × 100nF / 16V（0402/0603）
  - C23：4.7µF / 10V（0603/0805）
- 复位与启动：
  - R10：NRST 上拉 10k 到 3V3
  - C24：NRST 到 GND 100nF
  - R11：BOOT0 下拉 100k 到 GND（若封装有 BOOT0 引脚）
- SWD 调试座：
  - J5：SWD 4~6Pin（SWDIO, SWCLK, NRST, 3V3, GND）

接口分配建议：

- USART1：给 SIM7080G
- USART2：调试日志口（可接 USB‑TTL 焊盘）
- SPI1：W25Q64 Flash
- I2C1（可选）：IMU

---

### 2.5 离线存储（SPI NOR Flash）

- U5：Winbond W25Q64JVSSIQ（SOIC‑8，8MB）
- 去耦：
  - C30：100nF
  - C31：1µF（可选）
- 串联电阻（减振铃，靠近 MCU）：
  - R20~R23：SPI SCK/MOSI/MISO/CS 各 22Ω（可选位，先放 0Ω 也行）

连接：

- U5 VCC → 3V3，GND → GND
- U5 CS/SCK/MOSI/MISO ↔ MCU SPI
- WP/HOLD 上拉到 3V3（R24=10k，或直接拉高）

---

### 2.6 电池电压采样（36V 电量估算）

- 分压电阻（到 ADC）：
  - R30=330k（上）
  - R31=27k（下）
  - 42V 满电时 ADC 点约 3.2V（在 3.3V ADC 范围内）
- RC 滤波：
  - C40=100nF（ADC 点到 GND）
- 保护（可选）：
  - D7：ESD/钳位到 3V3（小信号 TVS 或用 MCU 内部钳位+串阻）
  - R32：串阻 1k（到 ADC 引脚）

网络：

- VIN_RAW → R30 → VBAT_SENSE → R31 → GND
- VBAT_SENSE → R32 → MCU_ADC
- VBAT_SENSE 对 GND 并 C40

---

### 2.7 可选：IMU（用于运动判定/抗漂移）

- U6：Bosch BMI270（LGA）
- 供电：3V3（或 1.8V 版本按型号）
- 去耦：100nF + 1µF
- I2C 上拉：
  - R50、R51：2.2k 到 3V3（SCL/SDA）

## 3. 方案 A2（推荐）BOM 汇总（关键料）

> 以下为“主料+关键无源+关键保护”，足以画全原理图并下单打样。

### 3.1 主料（IC/模块/连接器）

- U1：TPS54260DGQR（HV Buck 60V 2.5A）
- U2：AP2112K‑3.3（3.3V LDO）
- U3：SIM7080G（Cat‑M/NB + GNSS）
- U4：STM32G031K8T6（MCU）
- U5：W25Q64JVSSIQ（SPI Flash 64Mbit）
- J2：Nano‑SIM 卡座（503398‑1892 或同等）
- J3/J4：u.FL 天线座（U.FL‑R‑SMT）
- J5：SWD 调试座
- J1：电源输入连接器（XT30U‑M 或防水航插）

### 3.2 电源关键无源

- L1：10µH ≥4A 屏蔽电感
- D1：SS56（反接串联）
- D3：SS56（Buck 续流肖特基）
- D2：SMBJ58A（输入 TVS）
- C1：100µF/63V（输入）
- C2/C3：4.7µF/100V X7R（输入）
- C4/C5：220µF/6.3V 聚合物（4V 输出）
- C6/C7：22µF/10V X5R（4V 输出）
- 反馈：RFBB=10k，RFBT=40.2k，Cff=100pF

- 蜂窝 VBAT：470µF + 2×22µF + 2×100nF（最小组合；空间允许再加 100µF）

## 4. 方案 A1（备选）：4G Cat.1 + 独立 GNSS（更贵更大，但带宽更强）

如果你明确要 Cat.1（带宽/时延更好），电路块基本一致，只是把 U3 换为 Cat.1 模组（如 EC800M‑CN）并新增 U7 GNSS 模组（如 L76K/NEO‑M8N），同时：

- LTE 模组 VBAT 仍需 3.8~4.2V 且脉冲电流更大，C10~C17 的容量必须更大（建议总聚合物电容 ≥1000µF）
- GNSS 模组供电用 3.3V，UART 连接 MCU，GNSS 天线独立

## 5. PCB 体积压缩与布局硬规则（否则很容易不稳定）

- U1、L1、D3、C2/C3/C4/C5 必须靠近，SW 节点铜皮尽量小
- 蜂窝模组 VBAT 去耦（聚合物电容+陶瓷）必须贴近 VBAT 引脚，地回流要短粗
- 天线座区域 keepout，射频线 50Ω，地过孔围栏
- Buck 的电感与 SW 节点远离 GNSS 射频与天线
- 建议 4 层板（顶层信号/内层地/内层电源/底层信号），体积更小也更稳

## 6. 固件端实现（与硬件接口一一对应）

- UART(USART1)：SIM7080G AT 控制、MQTT/HTTP 上报
- GNSS 数据：
  - 走模组内置 GNSS 的 NMEA 输出（同 UART 或第二串口/虚拟通道，按模组能力）
- SPI：W25Q64 环形缓存（轨迹点、事件）
- ADC：VBAT_SENSE 电压估算
- 可选 I2C：IMU 运动判定（静止/骑行）

## 7. 你下一步可以直接开始画图的“网络名清单”

- VIN_RAW：D1 后输入母线（带 TVS/电解）
- VIN_BUCK：FB1 后 Buck 输入（贴近 U1）
- VOUT_4V：Buck 输出（给 SIM 模组 VBAT）
- VBAT_SIM：模组 VBAT 去耦网络
- VOUT_3V3：LDO 输出（给 MCU/Flash/IMU）
- UART_SIM_TX/RX：MCU↔SIM
- SIM_CLK/DATA/RST/VDD：SIM 卡
- RF_LTE / RF_GNSS：两路射频
- VBAT_SENSE：电池采样分压点

## 8. 成本与体积预估（粗略）

在国内常见采购渠道，方案 A2 的关键料成本大致：

- SIM7080G：约 35~60
- STM32G0：约 8~18
- TPS54260 + 电感 + 肖特基 + 聚合物电容：约 20~35（取决于电容规格）
- Flash + SIM 座 + u.FL + TVS/ESD：约 10~20
  合计：大概率能压在 100 左右（需根据你实际采购渠道确认）。
